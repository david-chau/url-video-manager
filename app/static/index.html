Cookies checking…

No auto-login exists for this — Google killed the OAuth flow yt-dlp used to use. Export cookies.txt from a real signed-in browser session, then paste or upload it here. Use a throwaway Google account if you can — scripted cookie use carries ban risk.

How long they last: typically 2 weeks to a few months, not fixed. YouTube actively rotates cookies on any tab left open, which kills an exported copy early — export from an incognito/private window, close it right after signing in, and don't reopen youtube.com in it. If jobs start failing with "sign in to confirm you're not a bot", that's your signal to re-export.

How do I get cookies.txt?
Desktop
Firefox — cookies.txt addon.
Chrome — Get cookies.txt LOCALLY (the plain "Get cookies.txt", no LOCALLY, was pulled from the Chrome Web Store as malware — don't use that one).
Sign into YouTube, click the extension, export, paste the contents above.

Mobile
Android — install Firefox for Android (regular Firefox app), then inside it add the YT-DLP Cookie Exporter addon via Settings → Add-ons. Sign into YouTube, export, paste.
iOS — Firefox and Chrome on iOS do NOT support extensions at all (Apple blocks it, both apps are just Safari underneath) — don't bother installing Firefox for this. Instead: install Cookie-Editor from the App Store, enable it in Settings → Safari → Extensions. Sign into YouTube in Safari, open Cookie-Editor from the address bar, export as Netscape format, paste.
